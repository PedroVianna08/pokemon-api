# PokéAPI - Consulta de Pokémon

## Autor

Pedro Moita Vianna Bastos - Matrícula 22610254

## Descrição

Aplicação web para consultar informações de Pokémon utilizando a PokéAPI.
O usuário pode pesquisar um Pokémon pelo nome e visualizar seus principais dados.

## API utilizada

- PokéAPI
- Endpoint: https://pokeapi.co/api/v2/pokemon/{nome}

## Funcionalidades

- Pesquisa de Pokémon pelo nome
- Exibição da imagem do Pokémon
- Exibição de altura e peso
- Exibição de tipos e outras informações
- Tratamento de erros quando o Pokémon não é encontrado
- Interface responsiva e organizada
